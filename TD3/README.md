# TD 3

Application et mise en place de toutes les règles d'entreprise.

## Situation initiale

- Un port 8080 accessible sur tout le réseau.
- Duplication des variables.
- Pas de gestion des secrets
- Pas de restriction de capabilities
- Pas de séparation des réseaux.
- Pas d'usage de revert-proxy
- Pas de limites de container
- Pas de health check, pas de d'ordre dans le démarrage malgré les dépendances.

Mettons en place cette même API de façon sécurisée !
